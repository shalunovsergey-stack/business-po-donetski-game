# БИЗНЕС ПО-ДОНЕЦКИ: Свари сыр, если сможешь

Минимальная мобильная оболочка browser-game для «Сергеев СырЪ». Block 0 содержит стартовый экран и пустую игровую сцену с HUD; механики пока нет. Внешних библиотек нет: нужен только установленный Node.js.

## Установка

В PowerShell откройте папку проекта:

```powershell
cd "C:\Users\Acer\Documents\создание макс бота\business-po-donetski-game"
```

## Запуск разработки

```powershell
npm run dev
```

Откройте адрес, который выведет сервер (обычно `http://127.0.0.1:5173`).

## Production build

```powershell
npm run build
```

Готовые статические файлы появятся в папке `dist`. Их можно разместить на обычном static hosting.

## Структура

* `index.html` — мобильный viewport и точка входа;
* `src/main.js` — переключение стартовой и игровой сцен;
* `src/style.css` — адаптивный интерфейс и placeholder-сцена;
* `dist/` — результат сборки, создаётся командой build.

## Проверка

1. На стартовом экране видны название, подзаголовок и кнопка «НАЧАТЬ СМЕНУ».
2. Кнопка открывает сцену с показателями: Деньги, Нервы, Сыр, Электричество.
3. Кнопка «На старт» возвращает назад.
4. Уменьшите ширину окна браузера до 390 px: HUD должен стать сеткой 2 × 2, без горизонтальной прокрутки.
